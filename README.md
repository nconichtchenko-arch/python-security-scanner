# Python Security Scanner

Простой сканер уязвимостей в Python-коде.

## Возможности

- 37 правил для поиска уязвимостей
- Фильтр по серьёзности
- JSON-отчёт
- Красивый вывод через rich

## Установка

pip install -r requirements.txt

## Использование

python scanner.py ./my_project
